# Legacy Scripts

The following scripts are retained as historical experiment records from the
original development process:

- `TRAIN.py`, `TRAIN_multi_image_batch.py`, `TEST_Net.py`
- `trainn.py`, `traint.py`, `traint2.py`, `modified_traint.py`
- `trainnew*.py`
- `testn*.py`, `testcount.py`, `testnonepoint.py`, `testsjzq.py`

They may contain hard-coded local paths, old ablation settings, or display-only
OpenCV calls. Use the new reproduction entry points for current work:

- `train_spaceseg.py`
- `eval_spaceseg.py`
- `infer_spaceseg.py`
